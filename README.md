# Ziyue Wang — Personal Website

A responsive, single-page personal website built with plain HTML, CSS and a small amount of JavaScript. No build tools or package installation are required.

## Preview locally

Open `index.html` in a browser. For a local web server, run `python3 -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Publish for free

1. Create a GitHub repository and upload the contents of this folder.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub Pages will publish the site at `https://<username>.github.io/<repository>/`.

## Before publishing

- Confirm all experience dates and public descriptions.
- Replace LinkedIn profile links with direct post or article links where available.
- Add approved project photography in `images/` and update the CSS if desired.
- Add an email link only if you want that address to be public.
- Check any employer and community guidelines before sharing project details.
